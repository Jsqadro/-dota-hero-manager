# Учёт героев Dota 2

Консольное Java-приложение: герои dota 2 хранятся в собственной коллекции `SimpleArrayList`, обработка - через Stream API и собственные алгоритмы сортировки. Реализованы уровни 1, 2 и 3 итогового задания.

Модель `Hero`: имя, процент побед (0-100), основной атрибут (`strength` / `agility` / `intelligence` / `universal`). Имя уникально.

## Требования

-   JDK 17+
-   Maven 3.9+

## Сборка и запуск

```sh
mvn clean package
java -jar target/heroes.jar
```

Запуск без сборки JAR (для разработки):

```sh
mvn -q compile exec:java
```

## Тесты

```sh
mvn test
```

15 тестов (JUnit 5), сгруппированы по уровням задания: `Level1Tests` (меню, файлы, валидация, Stream API), `Level2Tests` (собственная коллекция), `Level3Tests` (сортировки). Отчёты в `target/surefire-reports/`.

## Меню

```
1. Добавить героя вручную
2. Загрузить героев из CSV/TXT
3. Отфильтровать и отсортировать по проценту побед
4. Показать всех героев
5. Получить героя по номеру в списке
6. Удалить героя по номеру в списке
0. Выход
```

В пункте 3 задаются: минимальный процент побед, алгоритм сортировки (1 - Stream API, 2 - вставками, 3 - слиянием) и направление (по возрастанию / по убыванию).

## Формат файла

CSV/TXT в UTF-8, разделитель - `;`, заголовок необязателен:

```csv
name;winRate;attribute
Axe;53.2;strength
Crystal Maiden;52,8;intelligence
```

Атрибут можно вводить и по-русски: `сила`, `ловкость`, `интеллект`, `универсальный`.

Примеры в `data/`:

-   `heroes.csv` - 5 корректных героев;
-   `heroes-invalid.csv` - 1 корректная запись и 7 некорректных (неверный процент, пустое имя, неизвестный атрибут, дубликат и т.д.) для проверки сообщений об ошибках.

## Быстрая проверка функционала

1. Запустить приложение, выбрать **2**, ввести `data/heroes.csv` - добавятся 5 героев.
2. Пункт **4** - показать всех.
3. Пункт **1** - добавить героя вручную (например `Pudge`, `48,5`, `сила`); при вводе неверного процента (например `130`) программа выдаст ошибку и запросит повторно.
4. Пункт **3** - порог `51`, алгоритм `1`, направление `1`; повторить с алгоритмами `2` и `3` и направлением `2`.
5. Пункт **5** - получить героя по номеру, пункт **6** — удалить.
6. Пункт **2**, файл `data/heroes-invalid.csv` - покажет пропуск некорректных строк с номерами строк и причинами.
7. Пункт **0** - выход.
